## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 71 题](/images/posts/turtle100/071.png)

*Python 海龟绘图 100 题——第 71 题*

## 解析：

绘制多个圆形。

## 答案：

**方法一 使用循环绘制圆**

```python
import turtle as t
s=40
for i in range(0,5):
    for i in range(0, 360):
        t.fd(0.0174*s)
        t.lt(1)
    s=s+10
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
s=40
for i in range(0,5):
    t.circle(s)
    s=s+10
```
