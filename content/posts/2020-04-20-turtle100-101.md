## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要用"叶子"函数画出一个花瓣状图案。一片叶子由两段圆弧组成，再用循环把 n 片叶子绕中心均匀排开，改变 n 就能得到不同花瓣数的图案。

## 知识点

- `def yuanhu(r, n)`：用 `t.circle(-r, n)` 画圆弧。
- `def yezi(r, n)`：循环 2 次画两段圆弧，转角 `180-n`，拼成一片叶子（花瓣）。
- `n=3`：叶片数量（注释里给出 n=4、n=5 两种图案）。
- `t.rt(360/n)`：每片叶子画完旋转 360÷n 度，均匀分布。

## 绘图思路

叶子函数画一片花瓣；外层循环 n 次，每画一片就转 360÷n 度。n=3 是三瓣、n=4 是四瓣、n=5 是五瓣图案。改 n 这一个数字，就能切换不同花瓣数的图案。

## 完整代码

```python
import turtle as t
def yuanhu(r, n):
    # 用 循环绘制
    # for i in range(0,n):
    #     t.fd(0.0174*r)
    #     t.rt(1)
    # 用 circle 方法绘制
    t.circle(-r, n)
 
def yezi(r, n):
    for i in range(0,2):
        yuanhu(r,n)
        t.rt(180-n)

# 图案一
n=3
# 图案二
# n=4
# 图案三
# n=5
for i in range(0, n):
    yezi(80, 90)
    t.rt(360/n)
```

## 关键步骤讲解

### 叶子函数

`yezi(r, n)` 两段圆弧 + 转 `180-n` 度，拼出尖形花瓣。

### 选择花瓣数

`n=3` 决定花瓣数量，注释里 n=4、n=5 是另两种图案。

### 均匀排布

`t.rt(360/n)` 保证 n 片花瓣绕中心均匀分布。

## 常见错误

- `180-n` 写错：花瓣形状不对。
- 把 `360/n` 写成固定角度：花瓣分布不均。
- `circle(-r, n)` 负号漏掉：圆弧方向反了。

## 练习

把 `n=3` 改成 `n=4` 或 `n=5`，直接得到四瓣、五瓣图案，对比三者差别。
