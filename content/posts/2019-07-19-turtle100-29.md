## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 29 题](/images/posts/turtle100/029.png)

*Python 海龟绘图 100 题——第 29 题*

## 解析：

循环绘制五条线。

## 答案：

方法一

```python
import turtle as t
for i in range(0,5):
    t.fd(100)
    t.bk(100)
    t.lt(45)
```

方法二

```python
import turtle as t
t.rt(180)
for i in range(0,5):
    t.fd(100)
    t.bk(100)
    t.rt(45)
```

方法三

```python
import turtle as t
for i in range(0,5):
    t.bk(100)
    t.fd(100)
    t.rt(45)
```
