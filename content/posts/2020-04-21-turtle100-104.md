## 解析：

绘制由圆弧组成的多边形。

## 答案：

```python
import turtle as t
def yuanhu(r, n):
    # 用 循环绘制
    # for i in range(0,n):
    #     t.fd(0.0174*r)
    #     t.rt(1)
    # 用 circle 方法绘制
    t.circle(-r, n)

n=6
m=100
for i in range(0, n):
    yuanhu(-40, -m)
    t.lt(m)
    t.rt(360/n)
```
