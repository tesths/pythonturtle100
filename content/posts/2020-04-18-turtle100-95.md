绘制叶子。

## 答案：

```python
import turtle as t
def yuanhu(r, n):
    # 用 循环绘制
    for i in range(0,n):
        t.fd(0.0174*r)
        t.rt(1)
    # 用 circle 方法绘制
    # t.circle(-r, n)

def yezi(r, n):
    for i in range(0,2):
        yuanhu(r,n)
        t.rt(180-n)

yezi(100, 80)
```
