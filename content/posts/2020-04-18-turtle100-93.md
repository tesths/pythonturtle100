## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 93 题](/images/posts/turtle100/093.png)

*Python 海龟绘图 100 题——第 93 题*

## 解析：

绘制由半圆组成的梅花。

## 答案：

方法一

```python
import turtle as t
def meihua(n, d):
    for i in range(0, n):
        for j in range(0, 180):
             t.fd(0.0174*d)
             t.rt(1)
        t.lt(180-360/n)
    return

t.lt(90)
meihua(3, 40)
# meihua(4, 40)
# meihua(5, 40)
```

方法二

```python
import turtle as t
def meihua(n, d):
    for i in range(0, n):
        t.circle(-d, 180)
        t.lt(180-360/n)
    return
t.lt(90)
meihua(3, 40)
# meihua(4, 40)
# meihua(5, 40)
```
