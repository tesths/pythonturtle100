## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要用"曲线"拼出一个正方形：每条边不是直线，而是一条由多段圆弧组成的波浪曲线。先定义画曲线段的函数，再旋转 90 度重复 4 次。

## 知识点

- `def youyuanhu`/`def zuoyuanhu`：画右弧、左弧的基础函数。
- `def youquxian`/`def zuoquxian`：把 2 段左右弧组合成一条波浪曲线。
- `for i in range(2)`：组合两段弧成一条曲线边。
- `t.rt(30)`：开画前调整方向。
- `t.rt(90)`：每画完一条曲线边转 90 度，拼出正方形。

## 绘图思路

把弧函数组合成"曲线边"函数：一条曲线边 = 两段左右弧交替。用 4 条这样的曲线边、每条之后右转 90 度，就围成一个"曲线正方形"。方法二用 circle 直接画弧，更简洁。

## 完整代码

**方法一**

```python
import turtle as t
def youyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.rt(1)
    return

def zuoyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.lt(1)
    return

def youquxian(r, n):
    for i in range(2):
        youyuanhu(r, n)
        zuoyuanhu(r, n)
    return

def zuoquxian(r, n):
    for i in range(2):
        zuoyuanhu(r, n)
        youyuanhu(r, n)
    return

t.rt(30)
for i in range(0, 4):
    zuoquxian(20, 60)
    t.rt(90)
```

**方法二**

```python
import turtle as t
def yuanhu(r, n):
    t.circle(-r, n)
    return

def youquxian(r, n):
    for i in range(2):
        yuanhu(r, n)
        yuanhu(-r, n)
    return

def zuoquxian(r, n):
    for i in range(2):
        yuanhu(-r, n)
        yuanhu(r, n)
    return

t.rt(30)
for i in range(0, 4):
    zuoquxian(20, 60)
    t.rt(90)
```

## 关键步骤讲解

### 基础弧函数

`youyuanhu`、`zuoyuanhu` 分别画右弧、左弧。

### 组合曲线边

`youquxian`/`zuoquxian` 把两段弧组合成一条波浪曲线。

### 拼成正方形

循环 4 次，每次 `zuoquxian(20, 60)` 画一条边、`t.rt(90)` 转 90 度。

## 常见错误

- 四段曲线方向不一致：正方形四条边形状应相同。
- `t.rt(90)` 漏写：拼不成闭合的正方形。
- 弧半径/角度参数写错：曲线长短不齐。

## 练习

把弧的角度参数 60 改成 45，观察每个波浪变平缓后的整体形状。
