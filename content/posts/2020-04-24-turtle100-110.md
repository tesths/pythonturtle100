## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要用"叶子"函数画出组合图案。一片叶子由两段相反的圆弧拼成；再用循环把多片大小递增的叶子排开，最后整体旋转。

## 知识点

- `def yuanhu(r, n)`：用 `t.circle(-r, n)` 画半径 r、角度 n 的圆弧。
- `def yezi(r, n)`：循环 2 次画两段圆弧，转角 `180-n`，拼成一片叶子。
- `for i in range(0, 4)`：外层 4 组。
- `s=20` 并 `s=s+10`：每组里 3 片叶子半径依次增大。
- `t.rt(90)`：每组结束后旋转 90 度。

## 绘图思路

先把"圆弧"和"叶子"封装成函数。一片叶子 = 两段同向圆弧 + 转 `180-n` 度；一组里放 3 片半径递增（20、30、40）的叶子；再用外层循环把这一组旋转 4 次（每次 90 度），得到中心对称的叶子组合。

## 完整代码

```python
import turtle as t
def yuanhu(r, n):
    # 用 循环绘制
    # for i in range(0,n):
    #     t.fd(0.0174*r)
    #     t.rt(1)
    # 用 circle 方法绘制
    t.circle(-r, n)
    return
 
def yezi(r, n):
    for i in range(0,2):
        yuanhu(r,n)
        t.rt(180-n)
    return

for i in range(0, 4):
    s=20
    for j in range(0, 3):
        yezi(s, 90)
        s=s+10
    t.rt(90)
```

## 关键步骤讲解

### 圆弧函数

`yuanhu(r, n)` 用 `t.circle(-r, n)` 画一段半径 r、圆心角 n 的弧。

### 叶子函数

`yezi(r, n)` 画两段相同圆弧，中间转 `180-n` 度，两端对接成尖叶。

### 大小递增

`s=20`、`s=s+10` 让同组 3 片叶子依次为 20、30、40。

### 整体旋转

外层 `t.rt(90)` 让 4 组叶子绕中心均匀分布。

## 常见错误

- `180-n` 角度写错：叶子会张得过大或过小、拼不成尖形。
- 忘记 `s=s+10`：三片叶子一样大，图案没有层次。
- 外层漏 `t.rt(90)`：4 组叶子叠在一起。
- `circle(-r, n)` 负号漏掉：圆弧方向反了。

## 练习

把内层 `range(0, 3)` 改成 `range(0, 4)`，并相应多递增一次半径，观察叶子数量的变化。
