## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 63 题](/images/posts/turtle100/063.png)

*Python 海龟绘图 100 题——第 63 题*

## 解析：

绘制小圆，外切三个均匀分布的大圆。

## 答案：

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,3):
    for j in range(0,120):
        t.fd(0.0174*10)
        t.lt(1)
    for j in range(0,360):
        t.fd(0.0174*40)
        t.rt(1)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
for i in range(0,3):
    t.circle(10, 120)
    t.lt(180)
    t.circle(40)
    t.lt(180)
```
