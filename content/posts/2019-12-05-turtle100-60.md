## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 60 题](/images/posts/turtle100/060.png)

*Python 海龟绘图 100 题——第 60 题*

## 解析：

绘制三角形和半圆。

## 答案：

**方法一 使用循环绘制圆**

```python
import turtle as t
t.fd(100)
t.lt(90)
t.fd(140)
t.home()
t.lt(90)
for i in range(0,180):
    t.fd(0.0174*50)
    t.rt(1)
t.rt(90)
for i in range(0,180):
    t.fd(0.0174*70)
    t.rt(1)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
t.fd(100)
t.lt(90)
t.fd(140)
t.home()
t.fd(100)
t.lt(90)
t.circle(50,180)
t.lt(90)
t.fd(100)
t.lt(90)
t.fd(140)
t.lt(90)
t.circle(70,180)
```
