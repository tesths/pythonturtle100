## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一个直角三角形和两个半圆组合成的图案。先用直线画出三角形的两条直角边，用 home() 回到原点，再画两个半圆弧。

## 知识点

- `t.fd(100)`、`t.lt(90)`、`t.fd(140)`：画出三角形的两条直角边。
- `t.home()`：回到原点并复位朝向。
- `for i in range(0, 180)`：小步画半圆。
- `t.fd(0.0174*50)`、`t.fd(0.0174*70)`：分别画半径 50 和 70 的半圆。
- `t.rt(90)`、`t.lt(90)`：调整方向衔接各段。

## 绘图思路

先把两条直角边画出来，用 `home()` 一键回到原点、朝向复位；然后调整朝向后用循环各画一个 180 度的半圆弧（半径 50 和 70）。直线与圆弧组合成题目图形。方法二用 circle 会更简洁。

## 完整代码

**方法一 使用循环绘制圆**

```python
import turtle as t
t.fd(100)
t.lt(90)
t.fd(140)
t.home()
t.lt(90)
for i in range(0,180):
    t.fd(0.0174*50)
    t.rt(1)
t.rt(90)
for i in range(0,180):
    t.fd(0.0174*70)
    t.rt(1)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
t.fd(100)
t.lt(90)
t.fd(140)
t.home()
t.fd(100)
t.lt(90)
t.circle(50,180)
t.lt(90)
t.fd(100)
t.lt(90)
t.fd(140)
t.lt(90)
t.circle(70,180)
```

## 关键步骤讲解

### 画直角边

`t.fd(100)`、`t.lt(90)`、`t.fd(140)` 画出直角三角形的两条边。

### 回原点

`t.home()` 回到坐标原点并复位朝向。

### 画半圆

`range(0, 180)` 用 `t.fd(0.0174*50)` 等画半径 50、70 的两个半圆。

## 常见错误

- 漏写 `t.home()`：半圆起点错乱。
- 半圆半径写错：两个半圆大小比例不对。
- `0.0174*半径` 的半径改错：弧长不匹配。

## 练习

把两个半圆半径 50、70 改成 40、60，观察整体图案的比例变化。
