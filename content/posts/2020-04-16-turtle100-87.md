## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 87 题](/images/posts/turtle100/087.png)

*Python 海龟绘图 100 题——第 87 题*

## 解析：

绘制三个圆弧组成的图形。

## 答案：

方法一

```python
import turtle as t
def banyuan(r):
    for i in range(0, 180):
        t.fd(0.0174*r)
        t.rt(1)
    return

t.lt(90)
for i in range(0, 3):
    banyuan(50)
    t.rt(60)
```

方法二

```python
import turtle as t
t.lt(90)
for i in range(0, 3):
    t.circle(-50, 180)
    t.rt(60)
```
