## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一个圆形和一个内接正方形（圆套正方形）。先用循环画圆，再转到合适的角度画出内接的正方形；正方形边长约 141，正好是半径 100 的圆的内接正方形边长。

## 知识点

- `for i in range(0, 360)`：小步转一圈画半径为 100 的圆。
- `t.fd(0.0174*100)`、`t.rt(1)`：画圆周的步长与转角。
- `t.rt(45)`：转 45 度，让正方形顶点对准圆的方位。
- `for i in range(0, 4)`：画正方形 4 条边。
- `t.fd(141)`、`t.rt(90)`：边长 141 = 100×√2，是圆内接正方形边长。

## 绘图思路

圆的内接正方形，对角线等于直径（200），边长 = 200÷√2 ≈ 141。所以先画半径 100 的圆，转 45 度定位后，用边长 141 画一个正方形，正方形的四个顶点正好落在圆上。

## 完整代码

**方法一**

```python
import turtle as t
for i in range(0, 360):
    t.fd(0.0174*100)
    t.rt(1)
t.rt(45)
for i in range(0, 4):
    t.fd(141)
    t.rt(90)
```

**方法二**

```python
import turtle as t
t.circle(100)
t.lt(45)
for i in range(0, 4):
    t.fd(141)
    t.lt(90)
```

## 关键步骤讲解

### 画圆

`range(0, 360)` 用 `t.fd(0.0174*100)`、`t.rt(1)` 画半径 100 的圆。

### 定位正方形成角

`t.rt(45)` 让正方形旋转 45 度，顶点对准圆周。

### 画正方形

`t.fd(141)`、`t.rt(90)` 重复 4 次，边长 141 是内接正方形边长。

## 常见错误

- 把 `t.fd(141)` 改成 100：正方形会缩到圆内部，顶点不在圆上。
- 漏写 `t.rt(45)`：正方形位置相对圆转动，顶点对不上。
- 圆半径写死与正方形边长不匹配。

## 练习

把圆的半径 100 改成 80，正方形边长改为 80×√2≈113，观察整体比例是否依然吻合。
