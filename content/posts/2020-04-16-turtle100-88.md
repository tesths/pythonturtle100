## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 88 题](/images/posts/turtle100/088.png)

*Python 海龟绘图 100 题——第 88 题*

## 解析：

绘制圆形套正方形。（此题给的两种方法起始位置不同，方法一从最上面开始，方法二从图中 O 点起始）

## 答案：

方法一

```python
import turtle as t
for i in range(0, 360):
    t.fd(0.0174*100)
    t.rt(1)
t.rt(45)
for i in range(0, 4):
    t.fd(141)
    t.rt(90)
```

方法二

```python
import turtle as t
t.circle(100)
t.lt(45)
for i in range(0, 4):
    t.fd(141)
    t.lt(90)
```
