## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 84 题](/images/posts/turtle100/084.png)

*Python 海龟绘图 100 题——第 84 题*

## 解析：

绘制嵌套正方形。

## 答案：

```python
import turtle as t
def zfx(c):
    for i in range(0,4):
        t.fd(c)
        t.lt(90)
    return
s=50
for i in range(0, 6):
    zfx(s)
    s=s+10
```
