## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 65 题](/images/posts/turtle100/065.png)

*Python 海龟绘图 100 题——第 65 题*

## 解析：

绘制五角星，每个角有一个小圆。

## 答案：

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,5):
    t.fd(100)
    t.rt(144)
    for i in range(0,360):
        t.fd(0.0174*10)
        t.lt(1)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
for i in range(0,5):
    t.fd(100)
    t.rt(144)
    t.circle(10)
```
