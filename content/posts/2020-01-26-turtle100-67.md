## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一把伞：先画伞面（由多个同侧圆弧拼成的拱形），再画伞柄。方法一用循环画弧，方法二用 circle 的负半径直接画弧。

## 知识点

- `for i in range(0, 90)`、`range(0, 180)`：画不同角度的圆弧段。
- `t.fd(0.0174*半径)`、`t.rt(1)`/`t.lt(1)`：小步画弧、控制方向。
- `t.circle(-30, 180)`：负半径表示圆心在另一侧，画伞面的弧。
- `t.circle(90, 180)`：大半径弧形成伞面主体。
- `t.rt(90)`、`t.fd(100)`：转到伞柄方向并画伞柄。
- `t.circle(-10, 180)`：伞柄末端的钩。

## 绘图思路

伞面是几段同侧圆弧拼出的半拱：小弧、大弧、小弧依次衔接，各段半径不同形成起伏的伞边。画完伞面转到垂直方向画伞柄，最后画一个半圆做手柄的弯钩。负半径 circle 让圆弧朝正确的一侧弯曲。

## 完整代码

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,90):
    t.fd(0.0174*30)
    t.rt(1)
t.lt(180)
for i in range(0,180):
    t.fd(0.0174*30)
    t.rt(1)
t.lt(180)
for i in range(0,180):
    t.fd(0.0174*90)
    t.lt(1)
t.lt(180)
for i in range(0,180):
    t.fd(0.0174*30)
    t.rt(1)
t.lt(180)
for i in range(0,90):
    t.fd(0.0174*30)
    t.rt(1)
t.rt(90)
t.fd(100)
for i in range(0,180):
    t.fd(0.0174*10)
    t.rt(1)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
t.circle(-30, 90)
t.rt(180)
t.circle(-30, 180)
t.rt(180)
t.circle(90, 180)
t.rt(180)
t.circle(-30, 180)
t.rt(180)
t.circle(-30, 90)
t.rt(90)
t.fd(100)
t.circle(-10, 180)
```

## 关键步骤讲解

### 伞面各段弧

依次用 90 度小弧、180 度弧、180 度大弧、180 度弧、90 度小弧拼出伞面。

### 转到伞柄

`t.rt(90)`、`t.fd(100)` 从伞面转到垂直方向画伞柄。

### 画手柄

`t.circle(-10, 180)` 画伞柄末端的半圆弯钩。

## 常见错误

- 各段弧的半径顺序写错：伞面形状不对称/高低不平。
- `circle(-30,...)` 负号漏掉：圆弧朝反侧，伞面拼不上。
- 伞柄方向 `t.rt(90)` 写错：伞柄歪斜。
- 手柄半圆半径太大或太小。

## 练习

把伞面大弧半径 90 改成 110，观察伞面更宽后的样子。
