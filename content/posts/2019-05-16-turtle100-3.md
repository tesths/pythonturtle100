## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一个三条边一样长的等边三角形。这里要注意内角和转角的区别：等边三角形的内角是 60 度，但 Turtle 画图时每次转的是外角，所以每画完一条边后要转 120 度。

## 知识点

- `for i in range(3)`：重复执行 3 次，正好对应三角形的 3 条边。
- `t.fd(100)`：每次画出一条长度为 100 的边。
- `t.rt(120)`：画完一条边后转 120 度，继续画下一条边。
- 等边三角形的内角是 60 度，Turtle 转弯时用的是外角 `180 - 60 = 120` 度。

## 绘图思路

等边三角形由 3 条相同长度的边组成，所以可以把“前进 100，再右转 120 度”看成一个动作，重复 3 次。循环能减少重复代码，也能更清楚地表达图形规律。

## 完整代码

```python

# 不使用循环。
import turtle as t

t.fd(100)
t.rt(120)
t.fd(100)
t.rt(120)
t.fd(100)
t.rt(120)

# 使用循环。

for i in range(3):
    t.fd(100)
    t.rt(120)
```

## 关键步骤讲解

### 找到重复动作

画三角形时，每一条边的画法都一样：先向前走，再转向。这个重复动作适合交给 `for` 循环完成。

### 确认循环次数

等边三角形有 3 条边，所以 `range(3)` 会让循环执行 3 次。每执行一次，就画出一条边。

### 使用外角转向

如果写 `t.rt(60)`，海龟转得不够，会画不出封闭的等边三角形。这里要写 `t.rt(120)`，因为 Turtle 转的是外角。

## 常见错误

- 把转角写成 `60`：这是三角形内角，不是 Turtle 每次要转的角度。
- 循环次数写成 `2` 或 `4`：边数不对，图形不会是等边三角形。
- 忘记缩进循环里的两行代码：Python 会报缩进错误，或者只重复其中一行。
- 三条边长度不一致：如果每次前进的数字不同，就不会画出等边三角形。

## 练习

试着不用循环，把三组 `fd()` 和 `rt()` 手动写出来，对比哪种写法更清楚。
