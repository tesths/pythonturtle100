## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 59 题](/images/posts/turtle100/059.png)

*Python 海龟绘图 100 题——第 59 题*

## 解析：

使用循环绘制由四个圆形。

## 答案：

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,4):
    for j in range(0,360):
        t.fd(0.0174*50)
        t.rt(1)
    t.rt(90)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
for i in range(0,4):
    t.circle(50)
    t.rt(90)
```
