## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画四个大小相同、位置依次旋转的圆。每画一个圆后右转 90 度，四个圆分别朝四个方向，形成对称图案。

## 知识点

- `for i in range(0, 4)`：画 4 个圆。
- 内层 `for j in range(0, 360)`（方法一）：小步画半径 50 的圆。
- `t.circle(50)`（方法二）：直接画半径 50 的圆。
- `t.rt(90)`：每个圆画完右转 90 度。

## 绘图思路

方法一用 360 小步画出半径 50 的圆，方法二用 circle 一行画圆。外层循环 4 次，每个圆画完右转 90 度，四个圆分别排布在上、右、下、左四个方向，形成对称图案。

## 完整代码

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,4):
    for j in range(0,360):
        t.fd(0.0174*50)
        t.rt(1)
    t.rt(90)
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
for i in range(0,4):
    t.circle(50)
    t.rt(90)
```

## 关键步骤讲解

### 画一个圆

方法一 `range(0, 360)` 画圆；方法二 `t.circle(50)` 直接画圆。

### 旋转排布

`t.rt(90)` 让四个圆朝四个方向均匀分开。

## 常见错误

- `t.rt(90)` 写错：四个圆位置分布不均匀。
- 圆半径与旋转不协调：图形不匀称。
- 方法一内层次数不是 360：圆不闭合。

## 练习

把 `t.rt(90)` 改成 `t.rt(60)`、循环改成 `range(0, 6)`，画六个圆围成的图案。
