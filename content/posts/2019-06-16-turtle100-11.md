## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 11 题](/images/posts/turtle100/011.png)

*Python 海龟绘图 100 题——第 11 题*

## 解析：

综合应用，绘制图形。

## 答案：

不使用循环。

```python
import turtle as t
t.fd(50)
t.lt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.rt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.rt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.rt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.rt(90)
```

使用循环 **方法一**

```python
import turtle as t
for i in range(0,4):
    for i in range(0,3):
        t.fd(50)
        t.lt(90)
    t.rt(180)
```

使用循环 **方法二**

```python
import turtle as t
for i in range(0,4):
    t.fd(50)
    t.lt(90)
    t.fd(50)
    t.lt(90)
    t.fd(50)
    t.rt(90)
```
