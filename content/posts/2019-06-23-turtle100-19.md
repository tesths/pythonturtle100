## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一个直角梯形。底边是 120 像素，右侧竖边是 50 像素，上边也是 50 像素，左侧斜边没有直接标出长度。先画出三条已知边，再用 `home()` 回到原点，就能画出最后一条斜边。

## 知识点

- `t.fd(120)`：画出底边。
- `t.lt(90)`：左转 90 度，准备画右侧竖边。
- `t.fd(50)`：画出竖边和上边。
- `t.home()`：从左上角回到原点，画出左侧斜边。

## 绘图思路

从原点向右画出 120 像素的底边，再左转 90 度向上画 50 像素的竖边。到达右上角后再左转 90 度，向左画 50 像素的上边。最后用 `t.home()` 回到原点，直角梯形就完成了。

## 完整代码

```python
import turtle as t

t.fd(120)
t.lt(90)
t.fd(50)
t.lt(90)
t.fd(50)
t.home()
```

## 关键步骤讲解

### 画出底边

海龟默认面向右方，`t.fd(120)` 会画出题图中最长的底边。

### 画出右侧竖边

底边画完后，左转 90 度。`t.fd(50)` 会向上画出右侧竖边，形成一个直角。

### 画出上边

再次左转 90 度后，海龟面向左方。继续 `t.fd(50)`，就能画出较短的上边。

### 用 home() 画左侧斜边

此时海龟位于左上角。`t.home()` 会让海龟回到原点，返回路径正好是直角梯形的左侧斜边。

## 常见错误

- 把底边 `120` 写成 `50`：梯形会变成很窄的形状。
- 忘记第二个 `t.lt(90)`：上边不会向左画。
- 在最后一条边使用 `t.fd()` 硬算长度：这里更适合直接用 `home()`。
- 在 `home()` 前抬笔：左侧斜边不会画出来。

## 练习

把底边 `120` 改成 `150`，观察左侧斜边会变得更长还是更短。再把上边 `50` 改成 `80`，看看梯形的倾斜程度有什么变化。
