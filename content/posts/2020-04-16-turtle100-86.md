## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 86 题](/images/posts/turtle100/086.png)

*Python 海龟绘图 100 题——第 86 题*

## 解析：

绘制三个圆弧组成的逗号。

## 答案：

方法一

```python
import turtle as t
def rbanyuan(r):
    for i in range(0, 180):
        t.fd(0.0174*r)
        t.rt(1)
    return

def lbanyuan(r):
    for i in range(0, 180):
        t.fd(0.0174*r)
        t.lt(1)
    return

rbanyuan(50)
t.rt(180)
lbanyuan(100)
lbanyuan(50)
```

方法二

```python
import turtle as t
t.circle(-50, 180)
t.rt(180)
t.circle(100, 180)
t.circle(50, 180)
```

方法三

```python
import turtle as t
def banyuan(r, d):
    for i in range(0, 180):
        t.fd(0.0174*r)
        if(d==1):
            t.rt(1)
        else:
            t.lt(1)
    return

banyuan(50, 1)
t.rt(180)
banyuan(100, 0)
banyuan(50, 0)
```
