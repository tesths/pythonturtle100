用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画一个长 140、高 80 的大长方形，并在它的正中间画一个 40×40 的小正方形。要观察的是：大长方形由长边和短边交替画成；小正方形要放在大长方形中心，所以它到四条边的距离相等，左右各留 (140-40)/2=50，上下各留 (80-40)/2=20。动手前先想清楚海龟画完外框后停在哪里、要怎么移动到内框的起点。

## 知识点

- `range(0, 2)`：循环两次，每次画两条边，正好画完长方形的四条边。
- `t.fd(140)` 和 `t.fd(80)`：分别画出大长方形的长边和短边。
- `t.lt(90)`：每画完一条边左转 90 度，沿长方形方向继续走。
- `t.pu()` 和 `t.pd()`：抬笔移动位置而不画线，到位后落笔继续画。
- `range(0, 4)`：循环四次，画出小正方形的四条边。

## 绘图思路

先把大长方形看成重复两次的动作单元：前进 140 画长边，左转 90 度，前进 80 画短边，左转 90 度。两轮下来外框画好，海龟回到起点。接着抬笔，沿水平方向前进 50、左转向上前进 20，正好到达中心小正方形的起点；落笔后，用“前进 40、右转 90 度”重复四次，画出 40×40 的小正方形。

## 完整代码

```python
import turtle as t
for i in range(0, 2):
    t.fd(140)
    t.lt(90)
    t.fd(80)
    t.lt(90)
t.pu()
t.fd(50)
t.lt(90)
t.fd(20)
t.pd()
for i in range(0, 4):
    t.fd(40)
    t.rt(90)
```

## 关键步骤讲解

### 循环画大长方形

`range(0, 2)` 重复两次，每次用 `t.fd(140)` 画长边、`t.lt(90)` 转向、`t.fd(80)` 画短边、再 `t.lt(90)` 转向。两轮下来正好围出 140×80 的长方形，海龟回到起点。

### 抬笔移动到内框起点

`t.pu()` 抬起画笔，`t.fd(50)` 沿水平方向走 50 像素，`t.lt(90)` 转向上，再 `t.fd(20)` 走 20 像素，到达小正方形的起点。这两段距离正是左右、上下留出的居中余量。

### 落笔画小正方形

`t.pd()` 落笔后，用 `range(0, 4)` 重复四次 `t.fd(40)` 和 `t.rt(90)`，画出边长 40 的小正方形。右转 90 度四次正好闭合。

## 常见错误

- 忘记 `t.pu()` 或 `t.pd()`：移动时可能多画出一条线，内框也可能画不出来。
- 定位数字 50 / 20 算错：小正方形会偏出中心，做不到居中。
- 内层循环只写 3 次：正方形少一条边，画不闭合。
- 长边和短边写反：`t.fd(140)` 与 `t.fd(80)` 弄混，外框比例会不对。

## 练习

把大长方形改成 200×100，先算一算居中余量（左右各 (200-40)/2、上下各 (100-40)/2），再改代码里的定位数字；也可以把内框小正方形边长 `40` 改成 `60`，注意居中余量要重新计算。
