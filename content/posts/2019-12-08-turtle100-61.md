## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题要画三个互相外切的等圆（半径 50），三个圆心连成三角形。每画一个圆后，抬笔沿特定方向移动 100 像素（一个直径），再画下一个圆，让圆两两相切。

## 知识点

- `for i in range(0, 3)`：画 3 个圆。
- `t.rt(90)`、`t.lt(90)`：调整画圆起始朝向。
- 内层 `for j in range(0, 360)`（方法一）：小步画半径 50 的圆。
- `t.pu()`、`t.fd(50)`、`t.lt(120)`：抬笔平移，让下一个圆与外切位置对齐。
- `t.pd()`：落笔画下一个圆。

## 绘图思路

三个等圆两两外切时，圆心连成边长为 2×半径=100 的正三角形。所以每画完一个圆，抬笔移动 100 像素并转 120 度，正好到下一个相切圆的圆心，再落笔画圆。

## 完整代码

**方法一 使用循环绘制圆**

```python
import turtle as t
for i in range(0,3):
    t.rt(90)
    for j in range(0,360):
        t.fd(0.0174*50)
        t.lt(1)
    t.lt(90)
    t.pu()
    t.fd(50)
    t.lt(120)
    t.fd(50)
    t.pd()
```

**方法二 使用 circle 方法绘制圆**

```python
import turtle as t
for i in range(0,3):
    t.rt(90)
    t.circle(50)
    t.lt(90)
    t.pu()
    t.fd(50)
    t.lt(120)
    t.fd(50)
    t.pd()
```

## 关键步骤讲解

### 画一个圆

内层 `range(0, 360)` 用 `t.fd(0.0174*50)`、`t.lt(1)` 画半径 50 的圆。

### 平移到下一个圆心

`t.pu()` 抬笔，`t.fd(50)`、`t.lt(120)`、`t.fd(50)` 移到相距 100、转 120 度的下一个圆心。

### 落笔继续

`t.pd()` 落笔画下一个圆。

## 常见错误

- 平移距离写错（不是约 100）：圆之间相切/相交关系不对。
- 转 120 度写错：三个圆排不成正三角形。
- 忘记 `t.pu()`/`t.pd()`：会带出多余的连接线。

## 练习

把圆半径 50 改成 40，平移距离同步改成约 80，观察三圆相切关系是否保持。
