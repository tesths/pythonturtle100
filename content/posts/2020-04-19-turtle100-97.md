## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 97 题](/images/posts/turtle100/097.png)

*Python 海龟绘图 100 题——第 97 题*

## 解析：

绘制曲线。

## 答案：

方法一

```python
import turtle as t
def youyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.rt(1)
    return

def zuoyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.lt(1)
    return

t.lt(90)
# 左曲线
zuoyuanhu(30, 90)
youyuanhu(30, 90)
zuoyuanhu(30, 90)
youyuanhu(30, 90)

# 右曲线
# youyuanhu(30, 90)
# zuoyuanhu(30, 90)
# youyuanhu(30, 90)
# zuoyuanhu(30, 90)
```

方法二

```python
import turtle as t
def yuanhu(r, n):
    t.circle(-r, n)
    return

t.lt(90)
# 左曲线
yuanhu(-30, 90)
yuanhu(30, 90)
yuanhu(-30, 90)
yuanhu(30, 90)
```
