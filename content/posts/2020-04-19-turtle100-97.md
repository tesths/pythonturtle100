## 题目

用 Python Turtle 绘制下面的图形。

## 题目说明

这道题用左右相间的圆弧拼成一条 S 形曲线。先定义画左圆弧、右圆弧的两个函数，再交替调用它们，画出连续的波浪曲线。

## 知识点

- `def youyuanhu(r, n)`：向右转的画右圆弧函数。
- `def zuoyuanhu(r, n)`：向左转的画左圆弧函数。
- `for i in range(0, n)`：小步画出角度 n 的圆弧。
- `t.fd(0.0174*r)`：每步弧长 = 0.0174×半径。
- `t.lt(90)`：开画前调整朝向。

## 绘图思路

把"朝一个方向画弧"封装成两个函数：右弧每次转 1 度、左弧每次左转 1 度。交替调用左、右弧函数，圆弧首尾相连，就形成一条上下起伏的 S 形曲线。方法二用 `t.circle(-r, n)` 直接画弧。

## 完整代码

**方法一**

```python
import turtle as t
def youyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.rt(1)
    return

def zuoyuanhu(r, n):
    for i in range(0,n):
        t.fd(0.0174*r)
        t.lt(1)
    return

t.lt(90)
# 左曲线
zuoyuanhu(30, 90)
youyuanhu(30, 90)
zuoyuanhu(30, 90)
youyuanhu(30, 90)

# 右曲线
# youyuanhu(30, 90)
# zuoyuanhu(30, 90)
# youyuanhu(30, 90)
# zuoyuanhu(30, 90)
```

**方法二**

```python
import turtle as t
def yuanhu(r, n):
    t.circle(-r, n)
    return

t.lt(90)
# 左曲线
yuanhu(-30, 90)
yuanhu(30, 90)
yuanhu(-30, 90)
yuanhu(30, 90)
# 右曲线
# yuanhu(30, 90)
# yuanhu(-30, 90)
# yuanhu(30, 90)
# yuanhu(-30, 90)
```

## 关键步骤讲解

### 两个方向的弧

`youyuanhu` 右转画弧、`zuoyuanhu` 左转画弧，方向相反。

### 交替拼接

依次调用 左→右→左→右，四段弧首尾相接成 S 曲线。

### 调参控制

半径 r 和角度 n 决定每段弧的弯曲程度和长度。

## 常见错误

- 左弧右弧调用顺序弄乱：曲线形状与参考图不符。
- `0.0174*r` 的半径写错：弧长与半径不匹配。
- 漏掉开头 `t.lt(90)`：整条曲线朝向不对。

## 练习

把四段弧的角度 90 改成 120，观察曲线变得更弯的效果。
