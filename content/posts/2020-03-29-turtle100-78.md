## 题目：绘制下面的图形

![Python 海龟绘图 100 题——第 78 题](/images/posts/turtle100/078.png)

*Python 海龟绘图 100 题——第 78 题*

## 解析：

绘制五个相同的菱形。

## 答案：

```python
import turtle as t
def lingxing1():
    for i in range(0,2):
        t.fd(50)
        t.rt(120)
        t.fd(50)
        t.rt(60)
    return

def lingxing2():
    for i in range(0,2):
        t.fd(50)
        t.lt(60)
        t.fd(50)
        t.lt(120)
    return
        
lingxing1()
t.fd(100)
lingxing1()
t.lt(60)
t.fd(50)
t.rt(60)
lingxing2()
t.bk(100)
lingxing2()
t.fd(50)
t.lt(60)
t.bk(50)
```
